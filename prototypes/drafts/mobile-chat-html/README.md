# Kissne Mobile Chat HTML Draft

> Draft only. This is not a product surface or an Android client.

This directory is a design prototype for the future Android Chat surface.

- It is intentionally self-contained: open `index.html` directly.
- It does not connect to Runtime, Conversation, History, Memory, Provider, or a device.
- Every displayed message and connection state is explicitly prototype data.
- The avatar uses a text placeholder rather than inventing a replacement character image.
- Production Android code belongs in `apps/android/` after the Android boundary and implementation tickets pass.
