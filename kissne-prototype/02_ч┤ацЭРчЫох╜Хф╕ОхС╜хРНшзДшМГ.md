# 素材目录与命名规范

## 本地目录

```text
assets_source/yeqingxu/
assets_source/user_lamb/
assets_working/yeqingxu/chat/
assets_working/yeqingxu/notification/
assets_working/user_lamb/
preview/
```

## 文件名

统一格式：

```text
<角色>_<场景>_<状态>_<版本>.<扩展名>
```

示例：

```text
yeqingxu_chat_idle_v01.png
yeqingxu_chat_thinking_v01.png
yeqingxu_chat_streaming_v01.png
yeqingxu_chat_completed_v01.png
yeqingxu_chat_error_v01.png
user_lamb_avatar_idle_v01.png
```

## 每项登记字段

`id`、`原始文件名`、`处理后文件名`、`角色`、`用途`、`状态`、`尺寸`、`格式`、`透明度`、`SHA-256`、`来源/授权`、`备注`。
