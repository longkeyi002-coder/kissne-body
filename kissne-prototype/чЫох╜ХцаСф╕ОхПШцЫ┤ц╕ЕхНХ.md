**入口页时序**（`.splash.is-final`，2.4s）：
```

素材  : 0–52% 隐藏 → 86% 全显
```
两层同为居中绝对定位，必须错开，否则 logo 与素材同框叠压。

**降级修复**：`prefers-reduced-motion` 原写 `.splash .splash__logo`（特异性 0,2,0），被状态规则
`.splash.is-final .splash__logo`（0,3,0）压掉而失效 —— 媒体查询**不提升特异性**。
改为与状态同特异性并后置；该模式下默认态把两层改为 `position:static` 上下排列，logo 与素材都可见且不叠压。

**关键 Bug 实测数据**（flex 滚动）：
```
修复前：client=691  scroll=691  canScroll=false  展开区高=327
修复后：client=691  scroll=732  canScroll=true   展开区高=368
```
原因：`.screen__body` 为 flex 纵向容器，子项默认 `flex-shrink:1`，内容超高时被压扁而非溢出
→ `scrollHeight === clientHeight` → 既不滚动又互相重叠。
修法：`.screen__body > * , .chatbody > * { flex-shrink: 0 }`。

### 这一天的教训（会重复踩）

1. **判角色朝向只能看视线**（瞳孔朝哪 / 哪只手拿手机），**不能看"头在左还是在右"**。
   我按头的位置判过一次，把狐狸翻对了、把小羊判反了，用户回「还是不对，羊的图也要翻」。
2. **`1fr` 不等于等宽**：格子里只要有不换行的长文字，列宽就会被撑歪（表情包页实测 80/80/98/89）。
   grid / flex 子项要加 **`min-width:0`**，标签文字改成固定行高 + 溢出裁切。
