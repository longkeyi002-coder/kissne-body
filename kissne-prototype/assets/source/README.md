# Prototype source assets

这里集中保存 Kissne 手机低保真原型使用的原始素材，只做目录分类，不修改图片内容。

## 分类

- `home-cards/`：4 张首页星卡
- `avatars/`：19 张叶青栩 / 小羊头像与全身素材
- `stickers/`：31 张表情包源图
- `splash-animation/frames-1080/`：8 张开屏动画帧
- `splash-animation/frames-cropped/`：8 张裁切后的开屏动画帧

共 70 张源素材。

## 边界

- 保留原始文件名和二进制内容。
- 只整理源素材目录结构。
- 不修改 `kissne-prototype/prototype/` 运行目录。
- 原型运行时素材继续由 `prototype/assets/` 管理。
