#/welcome
页面没能完整加载

这个页面不是单文件，它依赖同目录下的 5 个文件：

index.html
styles.css
core.js
screens-a.js
screens-b.js
app.js

如果只把 index.html 单独传到手机（微信 / QQ 发送、文件管理器里只挑了一个）， CSS 和 JS 不会跟过去，页面就会变成没有样式的纯文字。

正确做法：把整个 prototype 文件夹一起传过去， 然后在文件管理器里打开里面的 index.html。

更省事的办法：让 WorkBuddy 把它发布成一个网址，手机直接点链接就能看。
