# 素材需求清单

状态只允许使用：`已有`、`待处理`、`待确认`、`缺失`、`approved`。

## P0：聊天页面必须项

|素材|建议规格|用途|状态|
|-|-|-|-|
|叶青栩聊天头像 idle|透明 PNG，1024×1024，正方形|普通回复/待机|缺失|
|叶青栩思考/生成中|同一头像、轻微表情变化|pending / streaming|缺失|
|叶青栩说话中|同一头像、口部或眼神变化|增量回复|缺失|
|叶青栩完成|同一头像、完成态表情|completed|缺失|
|叶青栩取消/停止|同一角色、明确停止状态|cancelled|缺失|
|叶青栩错误/离线|同一角色、克制的错误状态|error / offline|缺失|
|应用图标|Android adaptive icon 前景/背景|启动器图标|缺失|
|启动画面图|需叶青栩确认构图|splash|缺失|

## P1：聊天体验补充

|素材|建议规格|用途|状态|
|-|-|-|-|
|小尺寸通知头像|256×256 或 512×512|系统通知|缺失|
|连接中/重连|透明 PNG 或动画源|transport reconnect|缺失|
|空 Conversation|透明 PNG，留白构图|首次进入|缺失|
|发送中/取消按钮图标|优先使用矢量图标|控件状态|缺失|

## P2：后续页面，不阻塞聊天

* 功能入口页插画
* 小机星/小行星场景
* 记忆库与关系图节点
* 实时语音状态
* 工具动作状态
* 用户小羊头像及其状态组

## 资产规则

* 保留透明边缘，不自动加白底或阴影。
* 同一角色状态组必须保持画布尺寸、头部位置和视觉比例一致。
* 每个状态至少提供 `idle / active / waiting / completed / error` 的命名或明确说明。
* 动画第一阶段只收静态关键帧；Lottie、Rive、PNG sequence 格式待素材确认后再定。
