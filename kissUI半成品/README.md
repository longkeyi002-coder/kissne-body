# Kissne 手机端低保真页面原型 · V0.1

本目录是按《Kissne 手机端设计交接文档 V0.1》搭出的**可运行手机端低保真原型**。
只验证页面结构、信息层级、页面跳转、状态变化、素材占位与后续接入方式；
**不含最终 UI、不含角色素材、不改动 Android 正式 UI**。

---

## 一、怎么运行

**方式 1：直接打开（最快）**
双击 `index.html`。纯静态、无依赖、不需要联网，双击即可运行。

**方式 2：本地起服务（推荐，手机也能看）**
```bash
cd prototype
python -m http.server 8080
```
然后浏览器打开 `http://localhost:8080`；手机在同一局域网时打开
`http://<电脑IP>:8080`，会自动切换成全屏手机样式（无侧栏）。

---

## 一之二、手机上怎么看（重点）

**⚠️ 这个页面不是单文件，必须整个文件夹一起打开。**

`index.html` 依赖同目录的 5 个文件：`styles.css`、`core.js`、`screens-a.js`、`screens-b.js`、`app.js`。
只把 **index.html** 单独传到手机（微信/QQ 发送、文件管理器里只挑了一个文件），
CSS 和 JS 不会跟过去，页面就会变成**没有样式的纯文字**——这是最常见的"手机打开不对"。

> 兜底：如果依赖没加载成功，页面会直接显示一段中文提示告诉你缺什么，不会白屏。

**做法 A：整个文件夹传过去**
1. 把 `prototype` 整个文件夹（含全部 6 个文件）拷到手机
2. 在手机文件管理器里进到该文件夹，点 `index.html`
3. 选「用浏览器打开」（Chrome / 系统浏览器），不要用聊天软件的内置预览

**做法 B：直接开线上链接**（推荐，最省事）

> **https://b693ca9ad1324c54b8601c648f1d98e7.app.workbuddy.host/?v=20260918x**（注：发布通道故障恢复中，线上可能仍为旧版，以版本号为准）

手机浏览器直接打开即可，不用传文件、不用折腾文件管理器。
**链接尾巴的 `?v=` 必须带上** —— 静态托管会缓存裸路径 `/?`，不带版本号可能拿到旧的 `index.html`，
进而引用到旧资源。每次发布后把 `?v=` 换成 `index.html` 里用的那个版本号。
线上版本与本地 `prototype/` 目录内容一致；本地改动**不会自动同步到线上**，
需要重新发布才生效。

**真机上的表现**
- 自动切成**全屏**：不显示电脑端的侧栏，页面铺满整屏
- 不画假的 9:41 状态栏，直接用手机自己的
- 底部按安全区留白，不会被手势条 / 浏览器底栏挡住
- 侧栏变成**抽屉**：屏幕右边缘中间有个 `≡` 小拉手，点它滑出页面和状态列表；
  点任意一项后抽屉自动收起，点遮罩或按返回键也能收起
- 输入框和底部导航不会被键盘顶掉

---

**怎么用（电脑上）**
- 左侧栏点**页面路由**切换页面；点**状态切换**看同一页面的各种状态；按 **← →** 方向键也能切状态。
- 页面里的按钮、返回箭头、卡片都是真的能点的，会按交接文档第六节跳转。
- 顶部「标注：开 / 关」控制占位标记文字是否显示（关掉后画面更干净，适合看整体）。
- 顶部「全部页面总览」（`#/overview`）把 13 个页面并排铺开，适合整体预览和截图。

## 三、状态覆盖一览

**01 入口页（开屏）**：定格·双角色 / 播放动画（冷启动） / 定格·logo

> 开屏页行为：**只有冷启动（= 本次页面加载）才播放动画，播完自动进 `#/connect`**。
> 在应用内切回 `#/welcome` 不会重播，直接显示定格双角色。
> 定格态用于截图对照；**点整屏可以手动重播**动画。

**02 设备连接页**：等待输入 / 输入不完整 / 正在连接 / 连接成功 / 配对码错误 / Key 错误 / 网络错误 / 设备不可用 / 高级设置展开

**04 首页**：设备在线 / 设备离线（离线时置灰聊天入口 + 提供「重新连接」）

**05 人人星（聊天）**：默认对话 / 空聊天 / 键盘弹出（打字中） / **历史搜索** / 消息发送中 / 正在输入 / 正在思考 / 正在回复 / 回复失败 / 设备离线 / 网络断开 /
**思考链（示例） / 工具调用四个例子（记忆检索 · 联网搜索 · 看日程 · 写备忘录）/ 小机星进入请示 / 「+」菜单展开 / 模型下拉展开 / 思考强度下拉展开**

- **顶栏右上角有历史搜索**（放大镜）→ `#/chat?state=search`：像微信的搜索记录那样**按时间线排列**
  （今天 / 昨天 / 更早 · 日期，每行 = 关键词 + 时间 + ✕），顶部有搜索框可**实时筛选**历史，
  右上角「清空」一键清空。数据在模块级 `SEARCH_LOG`，删除 / 清空都是真的生效（只在本会话内）。
  - **点一条会"定位原文"**：跳到 `#/chat?state=normal&find=<关键词>`，回到人人星后**自动滚到那条消息并描边高亮 1.8s**；
    找不到时顶部给一条 `没有找到「xx」，可能已被清理。` 的提示。
  - **整页是叠在人人星上的一层**：上半（搜索框那条）**100% 透明**，直接露出背后的人人星；
    下半的历史面板 **60% 透明**（`rgba(255,255,255,.4)` + `backdrop-filter:blur(9px)`，保证还读得清）。
  - ⚠️ 路由相关的坑：`nav(to)` 必须比对**完整 hash**，不能只比对路径 ——
    否则从 `#/chat?state=search` 点返回 `#/chat` 会被当成"同一页"只重渲染、state 清不掉，**回不去人人星**。

- **输入框可以真的打字**：回车或点发送 → 追加一条带头像 + 时间戳的用户气泡，
  随后回一条占位 AI 消息（原型不发起真实请求）。
- **打字时输入区整组抬起**：输入框获焦（或 `state=keyboard`）时，**表情面板 + 磁吸快捷条 + 输入框**
  一起被顶上去，下方露出 `键盘区域（占位）`。这块区域**透明**（只有一条虚线），
  框外不铺任何底色 —— 真机上这里就是键盘。
- **AI 头像上的文字会随动作变**（占位表现，真机换成对应表情 / 动图素材）：
  `打字` / `思考` / `深思` / `说话` / `记忆` / `联网` / `日程` / `便签` / `开门`。
  例如「联网搜索」那一条消息里，头像就是 `联网`，随后回复变成 `说话`。
- **聊天记录是模块级 `CHAT_LOG`**：切页、去通话页再回来，记录**都还在**。
  - 页面的**默认状态是「默认对话」**（`CHAT_STATES[0]`）——之前第一项是"空聊天"，
    于是 `#/chat` 永远显示"还没有消息"，从通话页回来就以为记录丢了。空态现在只能从侧栏手动切。
- **未读消息**：你没在看的时候进来的 AI 消息算未读 →
  - 聊天页输入区上方浮一个**小胶囊**「N 条新消息 ↓」（`.unread`），
    **点了跳到最早那条未读**（描边高亮一下），到底后自动消失；
  - 底栏「人人星」上同时挂一个**小角标**（数量由 `window.KSN.unreadBadge` 提供，
    core.js 的 `tabbar()` 渲染）。
  - 判定"你在看"：路由停在 `#/chat` **且**滚动条在最下面（`chatAtBottom()`）。
  - ⚠️ 我们自己的**程序化滚动不算已读**（`scrollGuard` 400ms 守卫）——
    否则"打开就滚到底"会立刻把未读清掉。
  - 侧栏有 `有未读消息（示例）` 状态可以直接看效果。
- **每条消息都带时间戳**（`09:36` 这类小灰字，我方靠右），真实聊天不可能没有时间。
- **气泡与 AI 文本均为 13px**（与输入框字号一致，不再头重脚轻）。
- **通话内容会记进这里**：通话页说过的句子逐条落进聊天记录，并有一条居中的
  `📞 语音通话（示例）· 00:32` 记录行（见 05b）。
- **小机星进入请示**：人类不能自己闯进小机星 → 点请示后弹出一张卡片
  （`叶青栩：可以，我开门给你`），**「批准进入」→ `#/universe?state=enter`**，「暂不进入」回聊天。
- **思考链（示例）**：AI 回复上方挂一块灰底虚线的思考过程块（`已深度思考 · 用时 3.2s` + 几条占位思路），
  真实思考内容由 Hermes 输出，原型只摆样式。
- **工具调用（示例）**：AI 回复前先出一张工具调用卡片（工具名 · 参数 · 返回 · 耗时），
  参数 / 返回值均为占位，真实调用由 Hermes 工具链完成。

**05b 通话 / 屏幕共享页**：通话中 / 正在连接 / 已静音 / 扬声器模式 / **屏幕共享中**

- 从**输入栏上方快捷条**的「语音通话」或「屏幕共享」进入。页面很干净：**叶青栩素材**（圆形占位）+
  状态（`通话中 · 00:31`，走字用 `tabular-nums`，宽度不变不抖）+ **静音 / 扬声器 / 共享屏幕**三个开关 +
  **挂断键**（听筒朝下，回到 `#/chat`）。
- **这一页不放实时字幕、也没有音量波形**：说的话**转成文字直接落到人人星的聊天记录**里
  （进入通话还会写一条 `📞 通话中（示例）` 的记录行，`CALL_LOGGED_AT` 防重复）。
- **屏幕共享**（`state=share`）：头像位置换成一块 16:10 的「正在共享这块屏幕（占位）」，
  第三个开关变成「停止共享」，挂断键文案变「**结束共享**」。
- **可以后台**：会话状态在模块级 `CALL`（active / kind / startedAt / muted / speaker），
  退出这一页只是离开界面，会话照旧 —— **手机外壳层会出现一条"流体云"提示**
  （`.pill`，第 6px、嵌在状态栏那一条里，`通话中 00:31 | 回到通话`），点一下回到通话页；
  挂断 / 结束共享才会把会话结束、提示消失。
  - 提示由 `app.js` 的 `phone()` 统一渲染（和底栏一样挂在外壳层，所以切任何页面都在），
    内容由页面层提供：`K.activityPill()` / `K.activityPillTime()`；计时由 app.js 每秒刷 `[data-pill-time]`。
- ⚠️ **这一页所有直接子项都必须 `flex:none`**（`.call > *`）：竖向 flex 容器里，
  一旦内容变高，子项高度会被压缩 —— 表现为**挂断键被挤成扁的**。这是本项目反复踩的坑。

- **顶端**：左侧 `叶青栩`，中间 `模型 ▾` + `思考强度 ▾`（两项都可点开下拉）。
  不放头像，也不放右上角表情图标；离线 / 断网由下方 banner 表达，头部不重复放状态 chip。
  - 字号刻意压小（名字 13px / 胶囊 10px，顶栏高 54px），不抢消息区的视觉。
  - 布局：返回键与名字都 `position:absolute` 脱离文档流，中间那组用 `justify-content:center` ——
    这样「模型 · 思考强度」在整条顶栏里**真正居中**（实测组中心 195 = 屏幕中心 195），
    且与左侧名字不重叠（名字占 40–79px）。
  - **两项都可点开下拉切换**：`模型`（Hermes 风格示例模型名，真实列表由 Hermes 返回）、`思考强度`（Hermes 自带档位）。
    下拉从顶栏下方浮出，带遮罩，点空白收回。
- **选择会真的生效**：选项通过查询参数传递（`#/chat?state=<原状态>&model=xx&effort=yy`），
  选完头部立刻变成所选值，并**回到点开菜单时所在的状态**（不会把正在看的对话丢掉）。
  - 参数由 `app.js` 的 `phone(screen, state, interactive, params)` 透传给页面（`ctx.params`）；
    `setState()` 也会保留 `state` 以外的参数，否则在侧栏切状态会把选择冲掉。
- **底部**是一条长的大圆弧输入框（48px、圆角 24px），三枚按钮**嵌在框内且背景透明**，不各自成块。
  顺序固定为：**`＋` 加号在最左 → 文本区 → `🎤` 语音 → `➤` 发送**（语音紧挨在发送左边）。
  离线或断网时整条变虚线框、三枚按钮置灰。
- **消息两侧都带头像**：AI 一侧是叶青栩的头像占位（`FOX_CHAT_AVATAR`），
  我这一侧是用户头像占位（`USER_AVATAR`）；我说的话在**用户气泡**里，靠右。
- **输入栏上方的磁吸快捷条**（`.quickbar`）：「**表情包 / 语音通话 / 屏幕共享**」三个小胶囊，
  吸附在输入框上沿（负下边距压住一点点 + 轻投影 + 毛玻璃）。这三件事**不再藏在「＋」里**。
- **表情包是开关，不是跳页**：点一下在输入栏上方长出**内嵌面板**（`.stkpanel`）——
  **只有两排、横向可滚**（`grid-auto-flow:column` + `grid-template-rows:repeat(2,…)` + `overflow-x:auto`），
  **不遮住整页消息**、也没有遮罩。面板里点一张就作为消息发出并收起面板；
  面板底部有「管理表情包」进管理页。再点「表情包」胶囊即收起。
- **输入框的 `＋` 可以点开**：**紧贴加号上方**弹出一个小浮层（带小箭头指向加号），
  里面只剩 **照片 / 文件**（占位入口）。浮层挂在 `.composer` 内部
  （`position:relative` 锚点 + `bottom:calc(100%+10px)`），不是从屏幕底端滑上来的整条面板。
- 占位说明：模型名用 **Hermes 风格的示例名**（Hermes-Lite / Standard / Pro / Max、本地模型），
  均标注「示例模型」；真实模型表由 Hermes 返回后整体替换。思考强度档位为通用命名。
  **这两项的值一律来自 Hermes，原型里的具体名字不可当成真实数据。**

**06 小机星页（叶青栩的家与外面的世界 · 像素场景）**：自动漫游 / 俯视·家里 / 俯视·院子 / 俯视·街道 / 俯视·公园 / 场景（沉浸）

页面里有**两个小人**：
- **叶青栩**（深灰）—— AI，按自己的作息自己走，用户控制不了
- **绿色小人** —— **由用户操控**，用右下角**半透明方向键**上下左右走

两层结构：

**① 俯视图** —— 四张地图叠在一起，同一时刻只显示一张
- **家里**：客厅 / 书房 在上，**走廊**横向贯穿，厨房 / 卧室 / 厕所 在下；走廊右端是**大门**。
  房间名、房门、家具都是纯色块。
- **室外**：院子 / 街道 / 公园，各有天空、地面与树 / 长椅 / 店铺 / 水池等色块，并标出**出口**。
- **叶青栩走门**，不是平移：位移按「房间 → 房门 → 走廊 → 走廊 → 目标房门 → 房间」的折线，
  以约 3% 一步、每步 80ms 推进（sprite 22×26，小号），走路时两条腿交替。
- **可以出门**：走到走廊右端的大门 → 切到院子 → 街道 → 公园，再原路走回来；
  跨多张地图时会**逐跳**穿过（`CHAIN` + `mapHops`），不是瞬移。
- **绿色小人也受同一套规则约束**：只能走房间 / 走廊 / 房门通道，**撞墙会被挡住**；
  走到门口会切到相邻地图。用户一按方向键，视角就从「跟着叶青栩」切换成「跟着你自己」。
- **进入小机星需要先请示**（人类不能自己闯进去）：
  - 默认只显示**叶青栩的小人**——你是从外面看他，没有绿色小人、没有方向键；
    页面上方有一条很轻的入口条「你还在外面 / 向叶青栩请示」→ `#/chat?state=request-enter`。
  - 在人人星里点「批准进入」后进入 `#/universe?state=enter`，**这时才有绿色小人 + 方向键**。
- **操控时镜头锁在自己身上**：一旦按了方向键（`driving`），叶青栩换地图也**不会**把画面带走；
  此时小人的点击目标也跟着当前位置实时更新。
- **走路节奏**：叶青栩每步约 2%、每步 170ms，到地方后停约 3.6s（够你看清它在做什么）；
  两人的位移都带 CSS 过渡，走起来是连续的，不是一格一格硬跳。
- 左下角只有一条很轻的状态文字，**文案只在地图切换的那一刻更新**，
  避免出现"文案说在公园、画面还在街道"的错位。
- **沉浸式：页面上没有任何原型注释**。

**② 场景视图（点开房间或地图进入）** —— 视觉游戏那种
- 舞台（墙 + 地板 + 物件）与对话框**上下分区**，所以小人不会被对话框压住。
- **背景素材（物件）永远可以点**：点一下，物件就地弹出**名牌**（「沙发」「书架」…），
  下方同时说明**这是什么**（例：「客厅 · 沙发 / 一张布面的双人沙发。」）。
- **叶青栩只有在真的待在这个房间时才会出现**：
  - 他在 → 场景里有 2D 叶青栩，点物件时他还会**接一句**（例：「这张沙发是我最喜欢的位置。」）
  - 他不在 → **房间里没有人、也没有任何 AI 回应**，点物件只说明物件本身是什么
- 这样做是为了不"骗人"：他在厨房的时候，点客厅不该冒出一个人来跟你说话。

**实现要点**
- **全部用纯色块拼，不生成任何图片**；地板/地砖是 `linear-gradient` 画的格子。
- 靠 `app.js` 的**页面级生命周期**（页面导出 `mount` 并返回 `dispose`）驱动走动，切页会自动清理定时器。
- "谁在哪"记在模块级变量 `AI_AT` / `ME` 里，所以**跨页面状态切换后仍然一致**。
- `walkable(map, x, y)` 判断能不能走；`EXITS` 定义各图的出口。
  - 室外地图额外有一条 `WALK_PATHS`（门 → 地面的竖直小路）：出门后的落点就在小路上，
    否则落点停在半空、一步都迈不动。
- **两个小人之间没有碰撞体积**：只有墙（`walkable`）会挡人；两个小人可以走到同一格。
  只有墙会挡，走到哪里都不卡。（历史：先做过"撞到人不动"→ 会把用户堵在门外；又做过"错位不重叠"；
  按最新要求**两者都删掉**。）
- **点击目标跟着当前位置**：`navForPos` / `syncNav` 在每个步点刷新点击目标，
  走在走廊里时点了不跳，避免"点一下又回到某个房间"。
- **获准进入的状态会一直保留**（模块级 `ENTERED`）：点叶青栩进场景、切到其它俯视图，
  都不会被踢回"外面"、不需要反复请示。只有 `state=enter` 会把 `ENTERED` 置为 true。
- **叶青栩的作息是「模块级引擎」，不挂在页面上**（`AI` 对象 + `aiEngine` 每 170ms 一步）：
  - **点房间进场景、切状态、切页，都只是"看"，不会影响他在做什么** ——
    页面只是画布：挂载时注册 `AI.repaint` 用来画，卸载时只注销绘制，他的行程照走。
  - **只有点他本人**（和他说话）才会让他停下：`aiPause(8000)` 停 8 秒，
    状态条变成「叶青栩 · 停下了 · 在听你说话」，同时照常进他的场景。
  - 走在半路时文案是「**正去X**」（不再出现"文案说在公园、画面还在街道"的错位）；
    进场景时如果点的是他正要去的地方，场景里会说「叶青栩正往这里走…」。
  - 作息进度 `AI.idx`、当前位置 `AI.pos/map`、目的地 `AI.coming` 全在模块级，切页回来接着过。
  - ⚠️ 反例（已废）：早先把作息写在页面 `mount` 里，`runMount()` 切状态会先调 `dispose`，
    行程整段作废 → 回来时按旧的「他在哪」重建 = **他被迫回到出发房间**。
- **两个小人共用同一套走路帧动画**（`.is-walking` 的腿交替步态）；绿色小人在连续迈步期间保持该类，
  停步 240ms 后才摘，不会动画没走完就断。
- 上色只需改 `styles.css` 里那组 `--px-*` 变量，不用动结构。

## 十、滚动 Bug（值得记一笔）

你反馈的"高级设置展开后被遮挡、无法滑动"是真 Bug，实测证据：

```
修复前：bodyClient=691  bodyScroll=691  canScroll=false   advH=327
修复后：bodyClient=691  bodyScroll=732  canScroll=true    advH=368
```

**原因**：`.screen__body` 是 flex 纵向容器，子项默认 `flex-shrink:1`。
内容超高时子项被**压扁**而不是溢出，导致 `scrollHeight === clientHeight`，
容器判定"无需滚动"——于是既滚不动，元素还互相重叠。展开区高度从 327 被压到实高 368 就是证据。

**修法**：`.screen__body > * , .chatbody > * { flex-shrink: 0 }`。
同一处也修了聊天页的消息区。这个坑只在内容超长时才显形，所以之前几页看着都正常。

## 十二、怎么接后端（接入清单）

> 这份是给"真的要写后端"那一步用的。原型里所有标着 **待接入 / 待实现** 的地方就是后端要填的洞。

### 0. 先分清三个角色
- **App（现在这份原型）**：只画界面、管交互，**自己不存数据**。
- **Hermes（你的后端）**：管 4 件事 —— ① 设备与账号 ② 模型 / 思考强度 ③ 对话与工具调用 ④ 记忆库。
- **设备**：手机侧那个真正干活的东西（本地模型 / 橘瓣之类）。App 连的是它，
  **配对码 + Key + 服务器地址**就是连它的凭据。

### 1. 先只做通这一条链路
```
填配对码 + 服务器地址 → 点「连接」→ 设备回「我在这」→ 进首页
→ 人人星发一句「在吗」→ 后端流式回「在的。」
```
这条通了，App 就有"活着"的感觉；其余功能都可以之后一件一件加。

### 2. 每个界面要问后端要什么

| 原型位置 | App 要问后端 | 后端要回 | 现在没它时的样子 |
|---|---|---|---|
| 设备连接页 | 配对码 / Key 对不对 | 成功 · 或失败原因（码错 / Key 错 / 网络 / 设备不在） | 4 种错误态都已画好 |
| 连接成功页 | 设备名 · 在线状态 · 当前模型 · 最近同步 | 设备信息 | 虚线 `待接入` |
| 首页设备条 | 设备名 + 在线吗 | 同上（可缓存） | 「设备名称待接入 · 连接后由设备返回」 |
| 人人星顶部两个胶囊 | **可用模型列表** + **思考强度档位** | `[{id,名称,说明}]`、`[{id,名称}]` | Hermes-Lite/Standard/Pro/Max（示例名） |
| 人人星发消息 | 把这句发给后端 | **流式**返回：思考链 → 工具调用 → 正文 | 「（占位回复）我收到了：…」 |
| 思考链（示例） | —— | 思考过程文本（可折叠） | `已深度思考 · 用时 3.2s` + 占位思路 |
| 工具调用（示例） | —— | 工具名 / 参数 / 返回 / 耗时 | 4 个例子：记忆检索·联网搜索·看日程·写备忘录 |
| 通话 / 屏幕共享 | 建立通话或共享（信令 + 授权） | 接通 / 失败 / 画面通道 | 只能切界面状态 |
| 记忆库 | 列表 · 详情 · 增删改 · 同步 | 条目（标题·内容·分类·时间·来源·写入方式） | 12 条假数据；搜索已标「待实现」 |
| 表情包 | 上传（**240×240 · ≤500KB · PNG/GIF**） | 存好后的地址 | 网格是占位 `STICKER_PACK` |
| 通知 | 新消息 / 连接状态 / 记忆同步 | 推送内容 | 8 种通知样式已画好 |

### 3. 三条"越早定越好"的约定
1. **一个流式格式**：AI 回复要能边生成边推（先思考 → 再工具 → 再正文）。没有它，打字机效果和思考链都做不出来。
2. **稳定的 id 命名**：模型 id、工具 id、记忆 id、设备 id，App 和原型里用的是同一套名字。
3. **错误要说人话**：至少区分「码错了 / Key 错了 / 设备不在 / 网断了」，正好对上原型那 4 种错误态。

### 3.5 硬验收（来自《Android UI 规划 v0.1》，接后端时必须满足）
这几条是**不可妥协**的，原型已经用界面把它们的"正确长相"画出来了：

| 要求 | 原型里的对应 |
|---|---|
| 配对码是**一次性**的；成功后保存的是 **device token**（不是把配对码一直留着） | 设备连接页 → 连接成功页；设备管理页「配对码 / Key / 服务器地址」 |
| 助手回复**流式增量**期间不能显示"完成"标记 | 聊天「正在输入 / 正在思考 / 正在回复（带光标）」三个状态 |
| 同一个 `message_id` 重试**不能产生第二个 turn** | 无重试重复态的界面（消息带时间戳，重复即错） |
| 取消后要有 **cancel acknowledgement**（或等价的"已取消"态） | 回复失败态 + 「重新发送」；取消态待补 |
| gateway 重启后：token、cursor、未确认回复**能恢复** | 设备管理页「重新连接」+ 记忆库「同步成功（12 条）」 |
| 断线期间**不能静默丢掉回复** | 聊天页离线 banner「消息将在网络恢复后重试」 |
| 不显示 provider key / session_key / cursor / pairing 细节 | 这些字段一个都没出现在界面上（只有"配对码 / Key"入口本身） |

### 4. 怎么验收（不看代码也能验）- 配对码故意填错 → 连接页要出「配对码错误」；
- 把设备网络断掉 → 首页出现「设备离线」条、聊天页输入框变虚线不可发；
- 发一句话 → 先「正在输入」，再出正文；期间切去别的页面再回来，**记录不能丢**；
- 打一通电话 / 共享一次屏幕 → 挂断后人人星里能看到 `📞 通话中（示例）` 的记录行和说过的话；
- 退出通话页 → 顶部应出现"流体云"提示，点一下能回到通话。

### 5. 现在的原型**不**包含什么（别误会）
- **不发任何真实网络请求**：所有回复都是本地占位文本；
- **不存任何数据**：刷新页面就回到初始状态（只有"本会话内"的临时状态）；
- **没有账号体系**：设置页里是本地账号 + `待接入`。

## 十三、代码上的坑（改的时候别再踩）

| 坑 | 现象 | 正确做法 |
|---|---|---|
| 页面 mount 里放长驻状态 | 切页/进场景后状态被重置（小机星"回到上一个房间"） | 长驻状态放**模块级**，页面只注册绘制回调 |
| 竖向 flex 的子项没写 `flex:none` | 内容一高就把子项**压扁**（挂断键变扁） | 容器内直接子项统一 `flex:none` |
| `core.js` 里写 `K.xxx` | **整个外壳渲染直接空白**（ReferenceError，`K` 在该作用域不存在） | core.js 内用 `window.KSN`；它是运行时调用，已构建完成 |
| `nav(to)` 只比路径 | 从 `#/chat?state=search` 点返回 `#/chat` 回不去（state 清不掉） | 比对**完整 hash** |
| `location.replace('#...')` 清 URL 参数 | `file://` 下**整页重载**，看着像"点了没反应" | 保留 hash + 用去重标记（`LAST_SENT_HASH`） |
| 程序化滚动当成用户已读 | 一进聊天页未读就没了 | `scrollGuard` 守卫 400ms |
| 媒体查询不提升特异性 | `prefers-reduced-motion` 降级被状态规则静默压掉 | 降级规则写在状态规则之后 / 提高特异性 |
